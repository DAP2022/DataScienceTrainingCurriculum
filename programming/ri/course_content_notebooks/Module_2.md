# MODULE 2 — Introduction to the Tidyverse: Tidy Data & dplyr
### Question:  What exactly makes data "tidy," and why does it transform the way we write analytical code?
### Answer:  We transition from the clunkiness of base R to the elegance of the tidyverse's grammar of data manipulation, using the dplyr package.

## Learning Objectives
•	Define "tidy data" (one observation per row, one variable per column) and identify violations in real datasets.
•	Work with tibbles and understand how they differ from base R data frames.
•	Use the core dplyr verbs: filter(), select(), mutate(), arrange(), group_by(), summarize().
•	Chain operations with the pipe operator (|> or %>%) for readable, sequential pipelines.
•	Pass a dplyr result directly into **ggplot2** using the pipe.

## In-Class Activities
•	Manipulate and graph a built-in dataset using a dplyr + ggplot2 pipeline.
•	Clean a messy dataset using tidyverse tools.
