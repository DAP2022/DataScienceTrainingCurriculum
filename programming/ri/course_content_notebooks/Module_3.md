# MODULE 3 — Hypothesis Testing: Developing an Assumptions Pipeline
### Question: How do we create a reproducible pipeline to ensure the assumptions of our powerful parametric statistical tests are met? 
### Answer: We establish a system of quick visualizations and built-in tests to test for normality.

## Learning Objectives
•	Apply the four-step hypothesis testing framework: state H₀/Hₐ → choose and run the test → compare p-value to α → conclude.
•	Distinguish Type I and Type II errors and understand statistical power.
•	Build a binomial distribution and apply binom.test() and prop.test().
•	Test normality using QQ plots and the Shapiro-Wilk test.
•	Calculate and interpret ROC/AUC for diagnostic classifiers.
